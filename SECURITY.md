# Security / 安全

Do not post real group reports, chat excerpts, account credentials, or member identities in public issues. A minimal fictional input is enough for most reproductions.

If you find a security issue, avoid disclosing exploitable details or private data publicly. Use the repository's private vulnerability-reporting feature when enabled; otherwise open an issue containing only a request for a private reporting channel. There is no guaranteed response time.

Generated pages contain all supplied evidence. Keep real-data output local and restrict sharing. Browser localStorage is not encrypted or a server backup. Do not use shared computers for private review without an appropriate local data policy.

真实报告不要放进公开 Issue。输出页面包含输入证据，本地存储不提供加密和云备份。请使用虚构数据复现问题，并按本群实际的数据访问规则保管页面。
