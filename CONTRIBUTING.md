# Contributing / 贡献

Use fictional members and messages in tests, examples, issues, and pull requests. Do not commit private reports, account configuration, credentials, personal exemption lists, or generated real-data workbenches.

Before proposing a change, read the input contract. Run the Python test suite documented in README. Keep English and Chinese documentation aligned. Preserve the missing-identity gate, protected-member separation, text escaping, atomic writes, and no-account-action boundary. Browser visual and live-account claims require their own explicit evidence.

提交前阅读输入契约，运行 README 中的测试，同步中英文说明。问题复现必须使用虚构数据。任何改动都应保留身份门槛、保护成员隔离、文本转义、安全写入和不执行账号操作的边界。
